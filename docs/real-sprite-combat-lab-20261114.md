# 실제 SPR 및 AI 계획 진입점 검증 — 2026-11-14

게임 수정이나 전체 전투 검증 완료를 의미하지 않는다. 현재 확인된 새로운 동기화 원인은 없다.

## 추가한 반복 시험

- `test-real-sprites.py`: 원본 0x4BDEA0 로더로 로컬 MFP의 SPR을 읽는다. 8종 646프레임의 원본 크기/충돌 사각형 함수를 호출하고, 각 300틱씩 서로 다른 로컬 플레이어·해상도·카메라 조건에서 원본 스케줄러를 실행한다. 유닛 전체 상태, 점유 격자, 관리자, 난수 및 시계 상태를 비교한다. 파일별 SHA256도 결과에 기록한다.
- `test-ai-plan-stages.py`: 실제 AAI 9개 계획의 진입 인덱스를 지정해 원본 AI 스케줄러를 반복 실행한다. 변형별 115인덱스, 각 3틱, 총 1,035틱. 건설 조건을 가짜 성공으로 바꾸지 않는다. 결과가 같아도 필요 건물이 없어 거부된 경로일 수 있으므로 자연스러운 후반 테크트리 완주로 계산하지 않는다.
- `test-combat-targets.py`: 원본 무기 초기화의 0x4856E0..0x4857C1 통계 계산 구간을 실행한다. 0번 무기 없음과 66개 무기 번호, 지상/공중 대상의 134조합으로 원본 0x445280 판정을 비교한다. 70개 허용, 64개 거부. 양쪽 결과뿐 아니라 공유 상태도 비교한다. 양쪽 모두 무조건 거부되는 무효 시험을 막는 assertion을 포함한다.

## 시험 환경의 경계

SPR 파일 읽기와 메모리 할당은 에뮬레이터에서 제공한다. 원본 픽셀 데이터는 로드하지만 Windows 렌더링 제출은 생략한다. 핸들은 시험에 필요한 슬롯/프레임 수만 구성한다. 지형은 평지 시험 환경이다.

전투 대상 판정은 무기/탄약 상태를 지정한 시험이며, 탄환 생성→충돌→피해→사망 전체 흐름은 아직 검증하지 않았다. 무기 초기화도 렌더러 자원 로딩 전까지다. 전투가 일어나지 않은 스케줄러 실행은 전투 성공 시험으로 계산하지 않았다.

AI 시험은 후기 계획 항목을 조회하지만, 모든 선행 건물과 업그레이드를 실제로 완성한 상태를 만들지는 않았다. 전체 후반 테크트리와 전체 전투 분기는 여전히 미검증이다. 네트워크와 실제 두 PC 경기도 이 시험의 범위 밖이다.

## 실행

기존 `scripts/test-simulation-regressions.ps1`에 세 시험을 추가했다. 실제 EXE/HED/MFP와 빌드된 런처가 필요하다. 상세 결과 JSON은 gitignored `.tools`에 남는다. 원본 데이터는 저장소에 추가하지 않는다.
