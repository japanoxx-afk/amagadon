# 내부 해상도 분석 / 0.2.0-preview

## 대상

Armageddon.exe는 x86, 파일 버전 1.0.0.1, 게임 데이터 버전 1.15입니다.
지원 원본 SHA-256: `34f0bf9ed99fbf3ab88c410a3a52a2f6904e7bc7f5b88fb4ebadc935c2e9b466`.
ACE.exe는 버전 메타데이터가 없으며 SHA-256은 `a1b1b0464ce5b9af1841973184adb8c9852ed78fbc922b182a1d90933877d507`입니다.
주요 런타임은 binkw32.dll 1.0t와 Mss32.dll 6.0i입니다. 게임은 DirectDraw/DInput/IMM32를 사용합니다.

원본 해시, 예상 수정 바이트, 완성 파일 해시를 확인해 별도 시험본을 생성합니다. 저장소에는 게임 EXE/데이터 대신 패치 레시피와 직접 작성한 추가 코드만 포함합니다.

## 구현

| 영역 | 변경 |
| --- | --- |
| 화면 | 8비트 표면, 소프트웨어 화면, 행 간격과 주소표를 1280×720으로 확장 |
| 지형 | 25×16 타일 순회를 40×23으로 변경. 끝 행은 화면 경계에서 잘림 |
| 카메라 | 이동 경계와 중앙 위치 변경. 음수와 작은 지도 방어 |
| HUD | 기존 800픽셀 HUD를 x=240, 화면 아래쪽으로 이동. 그리기·클릭 판정·HUD 텍스트 함께 이동 |
| 미니맵 | 위치와 공통 클릭 경계 이동. 5개 투영 모드별 카메라 테두리 확장 및 작은 지도 경계 제한 |
| 날씨 | 기존 객체/저장 크기 유지. 기존 400칸과 난수 호출 보존, 추가 520칸 별도 캐시와 난수 상태 사용. 래스터 행 간격 및 경계 변경 |
| 타일 안정성 | 시험 중 ID 65535가 표면 배열을 참조하는 접근 위반 확인. ID>=10000과 빈 표면 접근 차단 |
| 안개·오버레이 | 순회 폭과 타일 행 경계 확장 |

화면과 무관한 파일 크기나 명령 코드 상수는 수정하지 않았습니다. 사운드 화면 기준 값은 추가 분석이 필요하여 유지했습니다.

## 검증 범위

실제 수정된 x86 명령을 Unicorn에서 실행했습니다. OS/COM 경계만 시험용 구현으로 대체했습니다. 타일 입력, 프레임버퍼 경계, 날씨 업데이트/래스터, 게임 난수 보존, 카메라 경계, HUD 그리기·클릭 일치, 선택적 텍스트 이동, 미니맵 투영과 경계 등 12개 범주를 통과했습니다.

Windows 디버거로 별도 시험 설치를 30초 실행했습니다. 내부 1280×720, 소프트웨어와 DirectDraw pitch=1280을 확인했고 시작 단계에 예외는 기록되지 않았습니다. 시간 제한에서 시험 프로세스를 종료했습니다. 전투 검사가 아닙니다.

런처 검사는 백업/복원, 설정, 필수 파일, 원본 및 레시피 변조 거부, 시험본 생성·재사용·제거와 원본 보존을 포함합니다.

남은 검증: 실제 화면과 입력, 모든 종족·지상/공중 유닛·건물·탄환/효과, 미니맵 클릭 이동, 전투 안개, 저장/불러오기, 사운드, 게임 속도, Alt+Tab/DPI/IME, ACE 편집/저장, 장시간 플레이·성능 측정·멀티플레이. 안정판 또는 크래시 예방 완료로 표시하지 않습니다.

ACE는 실행 전 기존 래퍼를 복원하는 처리를 유지합니다. ACE 내부 바이너리 안정성 패치는 아직 구현하지 않았습니다.
