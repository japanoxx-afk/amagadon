Armageddon은 DirectInput, Miles Sound System, Bink를 사용합니다. ACE는 DirectSound와 Windows 공용 컨트롤/대화상자를 사용합니다.
원본 파일은 수정하지 않았습니다. 소스나 재현 가능한 크래시 덤프 없이 특정 메모리 접근 결함을 확정하지 못했습니다.

## 확인된 사항

- 제공된 DxWnd 설정에 현재 설치 경로가 아닌 `D:\armaggeddon\Armageddon.exe`가 지정되어 있습니다. 새 런처는 지정된 설치 경로와 작업 폴더를 사용합니다.
- ACE 원본 방식에서 편집기와 맵 화면을 확인했습니다.
- ACE에 cnc-ddraw/GDI 프로필을 적용하면 미니맵 색상과 지도 표시가 깨졌습니다. 최종 구현은 ACE 시작 전에 런처 래퍼를 복원합니다.
- 게임에 cnc-ddraw를 적용한 뒤 CREATE GAME 화면이 열리는 것을 확인했습니다.
- 백업/복원 자동 검사 통과.

## 제한과 후속 진단

1280×720은 출력 확대입니다. 원본 800×600 내부 해상도나 맵 시야 확대를 의미하지 않습니다.
단일 CPU와 그래픽 호환성 설정은 호환성 대책이며 게임 로직의 모든 크래시를 수정한 것은 아닙니다.
장시간 플레이, 모든 미션, 저장/불러오기, 네트워크, ACE 전체 편집 동작은 추가 검증이 필요합니다.
비정상 종료 시 런처 로그에 종료 코드/실행 파일 해시가 기록됩니다. 재현 맵과 조작 순서, Windows Application Error 이벤트 및 크래시 덤프가 확보되면 후속 바이너리 분석이 가능합니다.

게임 데이터와 개인 실행 로그는 저장소에 포함하지 않습니다.
