# Crazy Zone 사설 서버 (0.3.15)

런처의 **Crazy Zone 서버 / 접속**에서 서버 시작·종료와 게임 접속을 지원한다. Python이나 별도 서버 프로그램 설치 없이 런처에 포함된 C# TCP 서버가 동작한다. 창을 닫아도 서버는 런처가 종료될 때까지 유지된다.

1. 서버를 열 PC에서 게임 설치 경로를 지정하고 **Crazy Zone 서버 / 접속**을 연다.
2. TCP 포트 기본값은 9000이다. **이 PC의 방 접속 주소**에는 함께 사용할 LAN 또는 VPN의 IPv4를 지정한다. 어댑터가 여러 개면 자동 선택된 주소를 확인한다.
3. **서버 시작** → **이 서버로 게임 실행**을 누른다. 같은 PC의 서버 접속 주소는 `127.0.0.1`이다.
4. 다른 플레이어는 같은 런처에서 서버 PC의 LAN/VPN IPv4와 같은 TCP 포트를 입력하고 **이 서버로 게임 실행**을 누른다.
5. 게임에서 **Multi Play → Crazy Zone → Amagadon Private Zone**을 선택한다. ID는 영문·숫자·밑줄·하이픈 1~19자, 암호는 1~9바이트다. 새 ID의 첫 로그인으로 사설 서버 계정이 만들어진다. 다음부터는 같은 암호를 사용한다.
6. `Lobby` 채널로 들어가 방을 생성하거나 참가한다. 모든 플레이어의 게임 데이터와 맵이 같아야 한다.

서버는 대기실·채널·접속자·채팅·방 목록과 방장 주소를 관리한다. 실제 전투는 게임의 **DirectPlay TCP/IP**로 직접 연결한다. IPX 공급자는 Crazy Zone 접속에 사용하지 않는다. Windows DirectPlay와 TCP/IP 공급자가 필요하다. 서버 포트만 열었다고 인터넷 전투까지 연결되는 것은 아니다. 방장의 게임 주소에도 도달할 수 있는 LAN/VPN에서 우선 사용한다. NAT 통과·게임 데이터 중계 서버는 포함하지 않는다. 두 PC의 실제 전투 연결·장시간 플레이는 미검증이다.

설정/서버 데이터는 `%LOCALAPPDATA%\AmagadonLauncher\CrazyZone`에 둔다. 계정 파일은 임의 24바이트 salt와 PBKDF2 100,000회 결과만 보관한다. 원본 클라이언트의 로그인 통신 형식에는 TLS가 없다. 서버는 최대 24연결, 필드별 길이·초당 요청·송신 큐 한도를 적용하고 30초마다 heartbeat를 보낸다. 종료 시 연결과 방을 정리한다.

**로깅 리포트 ZIP**에는 서버 시작/종료, 연결, 명령 번호, 방 입장·대전 시작 기록과 게임의 Crazy Zone 접속/로그인/채널/방 상태가 포함된다. 계정 파일·비밀번호·채팅 원문은 서버 로그에 기록하거나 리포트에 포함하지 않는다. 기존 충돌 덤프의 메모리에는 입력 정보가 남을 수 있다.

## 분석 근거

지원 원본은 SHA-256 `34f0bf9ed99fbf3ab88c410a3a52a2f6904e7bc7f5b88fb4ebadc935c2e9b466`이다. 기존 `NetworkGuard`가 지원 해시와 원본 바이트를 먼저 확인한다. 선택한 서버의 주소·포트와 서버 목록은 첫 스레드 재개 전에 메모리에만 적용한다. HD/원본 EXE의 디스크 해시는 그대로이며 일반 게임과 기존 리플레이 실행에는 사설 서버 패치가 적용되지 않는다. 사설 서버 실행은 싱글플레이 리플레이 후킹을 사용하지 않는다.

- `0x469e17 → 0x4a0390`: 폐쇄된 별도 패치/서버 목록 다운로드. 사설 모드에서는 메모리에서 건너뛴다.
- `0x497b40`, `0x497b50`: 서버 선택 목록과 주소 선택. 사설 서버 한 항목을 제공한다.
- `0x495880`: 게임 대기실 TCP 연결. `0x4958aa` 주소와 `0x4eaab8` 포트를 지정한다.
- `0x4a3a50`, `0x4a3a80`, `0x4aabe0`: 송신 op 인코딩 및 전송. 무작위 r=`rand()%10000`에 대해 `<u16(op+r), u16(r-4443)>` 다음 필드를 보낸다.
- `0x495ab0`, `0x4aaa30/80`, `0x4aab00/40`: 수신 op 및 길이 접두 필드 해석. 서버 응답 op는 평문 1바이트이고 필드 길이는 little-endian u32다.
- `0x49740f`: 방 참가 송신 시 제목 길이를 암호 길이로 재사용하던 원본 오류를 사설 모드에서 수정한다.
- `0x496f80`: 방 생성 구조 88바이트. `0x497500` 방 참가 구조 120바이트. `0x497340` 방 목록 레코드 115바이트.
- `0x4761b0`, `0x476230`, `0x475910`: 원본 DirectPlay TCP 생성/참가. 참가 정보 +93의 방장 IPv4와 원본 포트 `0x1074`(4212)를 주소 구성에 사용한다.

| 요청 op | 역할 | 응답 |
|---|---|---|
| 2, 70 | 원본 버전/제품 정보 | 없음 |
| 3, 5 | 로그인/계정 등록 | 4/6 + 결과 1바이트 |
| 8 | 채널 목록 | 9 시작, 10 레코드, 11 끝 |
| 12, 14 | 채널 생성/입장 | 13/15 + 결과 |
| 17, 18 | 접속자 구독/해제 | 16 접속자 레코드 |
| 50 | 채팅 | 51 표시 문자열 |
| 74 | 방 생성 | 75 + 성공111 + 방 ID |
| 76, 77, 78 | 방 퇴장/목록 | 79 방 레코드 |
| 83 | 방 참가 | 84 + 성공111 + 길이120 + 참가 정보 |
| 80 | 방 실패/종료 후 채널 복귀 | 81 + 채널 선택 복귀2 |
| 85, 86, 87 | 시작·결과·상태 알림 | 서버 로그/방 목록 갱신 |
| 89 | 서버88 heartbeat 응답 | 없음 |

계정 등록 화면의 기타 원본 검증 경로 대신 첫 로그인의 사설 계정 생성 방식을 기본으로 안내한다. 공식 계정 데이터와 연결하지 않는다. 결과 알림은 진단용으로만 보관하며 랭킹 점수는 반영하지 않는다.

## 참고와 검사 범위

사용자가 지정한 로컬 `wanggun/dummyserver.py`, `임팩트오브파워/server/protocol.py` 및 `analysis/protocol.md`, `삼국지천명2/server/compat_server.py`와 `src/NetworkPatch.cs`를 읽었다. 연결별 송신 직렬화, 명령 단위 TCP 재조립, 서버/게임 포트 분리, 네이티브 송수신 코드 검증 방식을 참고했다. Crazy Zone 패킷은 해당 게임들의 프로토콜을 재사용하지 않고 아마게돈 EXE에서 별도로 복원했다.

`scripts/test-crazy-zone.py`는 실제 loopback TCP에서 분할/합쳐진 요청, 두 클라이언트, 계정·잘못된 암호·중복 로그인, 채널·접속자·채팅·방 생성/목록/참가/퇴장, 비정상 길이, 불완전 연결의 격리와 계정 해시 저장을 검사한다. 원본 x86 송신 빌더와 op 인코더, 수신 파서·채널/접속자/방 목록/참가 정보 해석, 패치된 주소/포트와 스택 복귀도 실행한다. 실제 런처 서버 시작과 Crazy Zone 계정 화면 도달을 관찰했다. 실제 두 PC 전투 성공을 의미하지 않는다.
